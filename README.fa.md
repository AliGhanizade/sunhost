# سان هاست (SunHost)

این پروژه به عنوان پروژه پایان‌ترم درس طراحی سایت دانشگاه صنعتی سجاد توسعه داده شده است.

هدف پروژه، پیاده‌سازی یک وب‌سایت شرکت هاستینگ همراه با بک‌اند نوشته شده با زبان Go بوده است.

---

## امکانات

- ثبت نام کاربران
- ورود کاربران
- ثبت لاگ کاربران
- پنل مدیریت
- نمایش زنده اطلاعات سیستم
- گزارش وضعیت سیستم
- صفحات استاتیک سایت
- استفاده از SQLite

---

## تکنولوژی‌ها

- Go
- Gin
- SQLite
- HTML
- CSS
- JavaScript

---

## اجرا

ابتدا وابستگی‌ها را نصب کنید.

```bash
go mod download
```

سپس پروژه را اجرا کنید.

```bash
go run .
```

پروژه روی آدرس زیر اجرا خواهد شد.

```
http://localhost:8080
```

## هدف پروژه

این پروژه به عنوان پروژه پایان‌ترم درس طراحی سایت در دانشگاه صنعتی سجاد پیاده‌سازی شده است.

در این پروژه موارد زیر تمرین شده است:

- طراحی REST API
- برنامه‌نویسی Backend با Go
- احراز هویت کاربران
- کار با SQLite
- ساخت پنل مدیریت
- سازمان‌دهی پروژه به سبک MVC

## وضعیت پروژه

این پروژه به عنوان پروژه پایان‌ترم درس طراحی سایت دانشگاه صنعتی سجاد توسعه داده شده است.

این مخزن صرفاً با هدف ثبت روند یادگیری و نمایش نمونه‌کار منتشر شده است.

لطفاً توجه داشته باشید که:

- پروژه در برخی بخش‌ها کامل نیست.
- ساختار کدها به طور کامل بازنویسی و بهینه نشده است.
- مستندات پروژه کامل نیست.
- تاریخچه کامیت‌ها بیانگر روند واقعی توسعه پروژه نیست.
- این پروژه برای استفاده در محیط Production طراحی نشده است.

هدف از انتشار این مخزن، نگهداری پروژه‌های قدیمی، نمایش روند پیشرفت و به اشتراک گذاشتن تجربیات برنامه‌نویسی است.
